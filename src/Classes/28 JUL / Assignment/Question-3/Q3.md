# Q3. Counter Split into Two Components (State + Props)

## Objective
Create a counter application where the **state is managed by the parent component**, while the child components are responsible for displaying the count and updating it.

## Requirements

- Keep the `count` state in the **parent component**.
- Create a `<Display />` component that:
  - Receives `count` as a prop.
  - Only displays the current count.
- Create a `<Controls />` component that:
  - Receives `setCount` as a prop.
  - Contains **Increase** and **Decrease** buttons.
- Clicking the buttons should update the count displayed in `<Display />`.

## Hint

Think about:
- Which component should **own the state**?
- How can a child component update the parent's state using props?

## Expected Component Structure

```text
App
├── Display
└── Controls
```

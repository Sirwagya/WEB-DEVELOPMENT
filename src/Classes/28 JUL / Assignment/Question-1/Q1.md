# Q1. Counter with Limit (`useState`)

## Objective

Build a counter application using React's `useState` hook. The counter should start at `0` and allow the user to increase or decrease its value within a fixed range.

## Requirements

- Create a `count` state initialized to `0`.
- Display the current count on the screen.
- Add two buttons:
  - **Increase**
  - **Decrease**
- The counter:
  - Must **never go below `0`**.
  - Must **never go above `10`**.
- When a limit is reached:
  - Either **disable the corresponding button**, **or**
  - Show an **alert** informing the user that the limit has been reached.

## Hint

Think about:
- How can `useState` be used to store the counter value?
- How can you prevent the counter from exceeding its limits?
- When should a button be disabled?

## Expected Output

```text
Count: 5

[Decrease] [Increase]
```

- Clicking **Increase** increments the count until it reaches `10`.
- Clicking **Decrease** decrements the count until it reaches `0`.
- The counter should always stay within the range **0–10**.

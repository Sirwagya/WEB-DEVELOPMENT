# Q2. Reusable Student Card (Props)

## Objective

Create a reusable `StudentCard` component that displays student information using props.

## Requirements

- Create a `StudentCard` component.
- The component should accept the following props:
  - `name`
  - `rollNo`
  - `course`
- In the parent component:
  - Create an array containing details of at least **3 students**.
  - Use the same `StudentCard` component to display all students.
  - Render the cards using the `map()` function.

## Hint

Think about:
- Why is creating reusable components better than duplicating code?
- How can `map()` be used to render multiple components from an array?
- Which props should each `StudentCard` receive?

## Expected Component Structure

```text
App
└── StudentCard (Rendered 3 times using map())
```

# Q5. Like Button with Count Display (State + Props)

## Objective
Build a simple Like Counter where the **parent component manages the like count**, while child components display the count and handle the button click.

## Requirements

- Keep a `likes` state in the **parent component**.
- Initialize the state with `0`.
- Create a `<LikeCount />` component that:
  - Receives `likes` as a prop.
  - Displays it in the format:

    ```text
    Likes: 5
    ```

- Create a `<LikeButton />` component that:
  - Receives a `handleLike` function as a prop.
  - Contains a **Like** button.
- Clicking the button should:
  - Increase the like count in the parent.
  - Automatically update the displayed count.

## Hint

Think about:
- Which component should own the `likes` state?
- How can a child component trigger an update to the parent's state?
- What props should be passed to each child component?

## Expected Component Structure

```text
App
├── LikeCount
└── LikeButton
```

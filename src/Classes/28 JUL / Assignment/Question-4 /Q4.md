# Q4. Todo Count Badge (State + Props)

## Objective
Build a simple Todo application where the **parent component manages the list of tasks**, while a child component displays the total number of tasks.

## Requirements

- Keep the tasks in the **parent component** as an array state.

  ```js
  ["Task 1", "Task 2"]
  ```

- Add:
  - An input field to enter a new task.
  - An **Add** button to append the task to the list.
- Create a `<Badge />` component that:
  - Receives the total number of tasks as a prop.
  - Displays it in the format:

    ```text
    Total: 3
    ```

- Display the list of tasks below the badge.

## Hint

Think about:
- Which component should own the `tasks` state?
- How can the total number of tasks be calculated?
- What props should be passed to the `<Badge />` component?

## Expected Component Structure

```text
App
├── Badge
├── Input
├── Add Button
└── Task List
```
